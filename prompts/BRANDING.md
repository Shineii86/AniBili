# AniBili Branding Generation Prompt

## Logo Prompt

```
Create a minimalist, modern anime streaming app logo for "AniBili".

Design requirements:
- Clean, flat design style
- Primary color: Red (#e63946)
- Background: Dark/transparent
- The logo should incorporate an abstract play button or streaming symbol
- Optional: subtle anime-inspired elements (stylized "A" or wave pattern)
- Should work well at small sizes (favicon) and large sizes
- No text in the logo itself (text will be added separately)

Style references:
- Modern streaming apps (Netflix, Crunchyroll)
- Minimalist tech logos
- Dark theme aesthetic

Output: PNG with transparent background, 512x512px minimum
```

## Banner/Social Media Prompt

```
Create a wide banner image for "AniBili" anime streaming platform.

Design requirements:
- Dimensions: 1200x630px (OG image standard)
- Dark background with subtle gradient (#08080c to #12121a)
- Central element: "AniBili" text in modern sans-serif font
- Accent color: Red (#e63946) for highlights
- Subtle anime-themed decorative elements (abstract shapes, dots, lines)
- Clean, professional appearance
- Should convey: streaming, anime, modern, clean

Optional elements:
- Subtle grid pattern in background
- Glowing accent effects
- Abstract anime character silhouettes (very subtle)

Output: PNG, 1200x630px
```

## Favicon Prompt

```
Create a simple favicon for "AniBili" anime streaming app.

Design requirements:
- 32x32px and 16x16px versions
- Simple, recognizable at small sizes
- Primary color: Red (#e63946)
- Could be a stylized "A" or play button icon
- No text (too small for text)
- High contrast for visibility

Output: ICO and PNG formats, multiple sizes (16, 32, 48, 64px)
```
